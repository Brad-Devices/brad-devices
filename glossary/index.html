Two ISAs, never one.
BradISA is the CPU. BradVector is the GPU. They meet on the BradFusion fabric and share SPMP memory — they do not share instructions, and no page on this site will tell you they do.

Not these: the fabric is BradFusion, never "BradNet". Ray tracing is BradRT, never "BradRays". Both survive in old drafts; neither is a real name.

The micro-words

The generic terms the names above are built from — each with its own one-line receipt.

TermOne honest line
P-coreperformance core — the big, fast side of a CPU die
E-coreefficiency core — the small, power-thrifty side
NPUneural processing unit — the AI math engine on-die
ISAinstruction set architecture — the vocabulary a processor speaks. Brad Devices has two: BradISA (CPU) and BradVector (GPU). They share memory, never instructions.
SRAMstatic RAM — fast, on-die memory
DRAMdynamic RAM — the big, off-die memory pool
GPUgraphics processing unit — the parallel math engine
SoCsystem on chip — CPU+GPU+memory+everything on one die
fabricthe interconnect wires that move data between dies
diethe physical slab of silicon a chip is cut from
stackthe whole Brad Devices architecture, one connected plan
