What is being built right now

The receipts pages show what shipped. This page shows what is moving — derived from the repository by the build itself, never typed by hand. If a stream stalls, the page is required to say so.

SHIPPED

BradISA V2 in RTL — the Falcon decoder

All 64 opcode slots decoded in RTL: 50 assigned across seven formats, 14 reserved and raising undef. The coverage testbench feeds every slot and is green. Simulation-verified; no FPGA bitstream yet.

last movement 2026-11-04 · the RTL, on GitHub
SHIPPED

BradISA V2 execute stage — the Falcon pipeline

ALU, immediates, loads and stores, branches, CALL/RET/JALR, and the forwarding that removes stalls. 60 execution checks on hand-encoded V2 programs, zero errors; undefined opcodes and divide-by-zero raise the fault line. Verilog only — the VHDL tree is still V1.

last movement 2026-11-04 · the RTL, on GitHub
SHIPPED

BradISA V2 assembler — table-driven, ABI-aligned

The V1 assembler is retired. The V2 one is two-pass and table-driven: 50 mnemonics, seven formats, ABI register names, labels, data directives. A new ISA drift gate compares the Verilog package, the C header and the assembler table, so the RTL and the toolchain cannot silently disagree. RET is 0xB8000000 and the link register is r15, matching the published ABI.

last movement 2026-11-04 · the assembler, on GitHub
SHIPPED

bradc-mini — the C-subset compiler that runs its own output

A TCC-class compiler for BradISA V2: int/void, functions with up to 8 arguments, locals, if/else, while, globals, arrays, pointers and int-field structs. A new in-process V2 emulator executes the emitted code in ctest, so add(3,4)=7, sum(10)=45 and the combined aggregate test are checked end-to-end, not just assembled.

last movement 2026-11-05 · the compiler, on GitHub
SHIPPED

The 64-slot decode-coverage gate

A testbench that feeds every one of the 64 opcode values and fails unless the 50 assigned slots decode with the right format and the 14 reserved slots trap. Wired into CI through tools/check_rtl.py, alongside the execution testbench.

last movement 2026-11-03 · the gate, on GitHub
SHIPPED

BradVector compiler — the vertical slice

PTX-text in, .bvbc out, nine kernels run lane-by-lane on BVRT, the full ctest suite green. Rung 1 lowers 64-bit loads and stores to two 32-bit accesses with a run-time 8-byte alignment check. Cubin, 64-bit ALU, atomics, doubles and predicated 64-bit accesses remain honestly unsupported.

last movement 2026-11-04 · the brad-cvt source, on GitHub
DESIGNED

BradKernel — ABI, trap entry and the boot seed

The second reconciliation pass wrote the V2 scalar ABI, the trap-entry sequence, the boot/schedule/switch seed, the CVT next-rung plan and the blocked register. The seed is designed and simulated on V1 — boot, a software-injected trap, syscall routing, context switch and a round-robin scheduler — while preemption, ECALL and the timer remain VISION because V2 assigns no ECALL opcode and the RTL has no exception logic. C10 (threads per Torox cluster) and R10 (Torox fault path) stay blocked pending the Architect.

last movement 2026-11-05 · the kernel docs, on GitHub
SHIPPED

BradSense-Renderer — spatial (M0), temporal (M1) and metrics (M2)

Three milestones ship: the spatial core, the temporal core, and the metrics harness with golden diffs that keep the numbers honest. All public and receipted. The real-resolution corpus and M3–M4 stay open; what comes next in the pipeline stays moat.

last movement 2026-11-05 · what ships today
SHIPPED

The corporate folder, assessed and updated

A deep audit of every governance document: the IP registry corrected to the shipped ISA spec, an index and audit record added. Two decisions were carried to the founder — the equity plan's calendar years (F7) and the five unbounded questions in EXCELLENCE_STRATEGY (F8) — and both are still pending.

last movement 2026-10-26 · the governance docs, on GitHub
SHIPPED

This site — one motion stack

One motion engine where there were two: GSAP + ScrollTrigger + Lenis replaced the retired Motion One — vendored, hash-gated, reduced-motion-safe, no-JS-readable. Every reading page loads it; the deck is deliberately self-contained.
