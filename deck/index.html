04 / 12
Memory

SPMP — one pool, not a hierarchy to argue about.

The Super Power Memory Pool replaces the CPU-side / GPU-side split with a single shared address space across the fusion fabric, so a kernel and the engine feeding it can touch the same bytes without a copy.

Underneath, BradRAM uses standard JEDEC DRAM dies. The intelligence sits on a separate Brad controller die as an L4 SRAM assistant cache. There is no custom Brad DRAM die — and we would rather say that plainly than let a reader assume one.

BradSense

A rendering component that ships, not a promise.

BradSense is our neural rendering path. The first milestone — the spatial core — is SHIPPED and measured: 39.43 / 39.44 / 39.57 dB PSNR across a test corpus, with tests asserting the pixel path itself: determinism, flat-region quietness, edge behaviour, anti-ringing bounds.

Further milestones are VISION. We are not going to describe unfinished work as if it were finished, and we are not going to describe a component by the ambition rather than the artifact.
