Processors

Two CPU dies, two instruction sets, no ports to write.

Two instructions sets, on purpose. The CPU speaks BradISA; the GPU speaks BradVector. They meet on the BradFusion fabric and share memory (SPMP) — not instructions. Because every Torox GPU die runs that one GPU ISA, a kernel written once decodes identically from integrated to flagship to datacenter. No GPU has to "wait for the CPU world."

BradChip fuses CPU, GPU and NPU on one package with a unified memory pool. BradXon is the flagship processor — its Adaptive Neural Fabric adapts the machine to the workload: compute partitions, a reconfigurable dataflow NPU, and a fabric governor that steers power, clock, and bandwidth. It reallocates budget, not silicon.

  • BradChip GEN 1 · DESIGNED — silicon designed
  • BradXon GEN 1 · DESIGNED — the flagship adaptive processor
  • Two ISAs by design — BradISA (CPU) and BradVector (GPU), never conflated
  • One BradVector GPU ISA across every Torox die — zero porting

Memory · BradRAM + SPMP

The end of "VRAM vs the rest."

One unified memory pool. The GPU reads and writes the same fabric the CPU does — zero-copy, no guest in someone else's PCIe lane.

  • SPMP — unified LPDDR, one pool, gigabytes
  • BradRAM — JEDEC LPDDR5X dies + a Brad controller with an L4 SRAM assistant cache
  • Infinity Buffer — the GPU's own on-die SRAM render cache
  • Zero-copy between CPU, GPU and NPU
  • GEN 1 · DESIGNED silicon designed
